# 我会替你留住故事

`astrbot_plugin_content_companion` 是陪伴系列的独立创作扩展，负责创作项目、续写、审校、创作记忆整理、作品封面，以及 QQ 空间动态工作台。

安装并启用后，陪伴主插件会优先通过扩展 API 调用创作能力；未安装或关闭时，主插件继续使用兼容实现。独立插件自己的数据是运行时主数据，旧版 `creative_projects` 和创作配置只在首次启动时作为迁移来源，不会持续回写旧文件。

插件页“QQ 空间与书柜”集中管理创作作品、QQ 空间动态读取、说说发布和基础联动状态。QQ 空间底层协议调用仍复用陪伴主插件的会话、Cookie 和平台适配，以保证拆分前的发送顺序、权限判断和 OneBot 兼容行为不变。未安装本插件时，陪伴插件保留旧 QQ 空间页面和运行链路作为兼容回退。

独立运行时，作品数据保存在 AstrBot 的插件数据目录 `creative_state.json`，使用 UTF-8 原子写入。首次启动会尝试读入旧陪伴插件的 `companions.json` 中的 `creative_projects`，导入后不修改旧文件。

从拆分前版本升级时，应先停止 AstrBot，安装本插件，再更新“我会永远陪着你”，最后统一启动。若本插件先于主插件加载，会保持迁移待定并在约两分钟内自动重试；主插件出现后再幂等导入旧作品、创作参数、QQ 空间开关和 Cookie。迁移完成前不会用本插件的默认值关闭旧 QQ 空间，已有非默认新配置也不会被旧值覆盖。

独立运行时可使用：

- `创作`：查看项目列表
- `创作 开始 <灵感>`：建立一个新项目
- `创作 续写 [作品标题]`：立即推进一段正文
- `创作 查看 [作品标题]`：读取作品正文
- `创作 分享 [作品标题]`：输出最近片段

封面生成会自动复用已安装的 `astrbot_plugin_image_companion`；没有可用生图后端时只记录真实失败状态，不会伪造封面已生成。

# 我会替你留住故事

`astrbot_plugin_content_companion` 是陪伴系列的独立创作扩展，负责创作项目、续写、审校、创作记忆整理和作品封面。

安装并启用后，陪伴主插件会优先通过扩展 API 调用创作能力；未安装或关闭时，主插件继续使用兼容实现。旧版 `creative_projects` 数据和创作配置保持读穿，不需要重新建立作品。

独立运行时，作品数据保存在 AstrBot 的插件数据目录 `creative_state.json`，使用 UTF-8 原子写入。首次启动会尝试读入旧陪伴插件的 `companions.json` 中的 `creative_projects`，导入后不修改旧文件。

独立运行时可使用：

- `创作`：查看项目列表
- `创作 开始 <灵感>`：建立一个新项目
- `创作 续写 [作品标题]`：立即推进一段正文
- `创作 查看 [作品标题]`：读取作品正文
- `创作 分享 [作品标题]`：输出最近片段

封面生成会自动复用已安装的 `astrbot_plugin_image_companion`；没有可用生图后端时只记录真实失败状态，不会伪造封面已生成。
